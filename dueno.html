Conectá tu cuenta de GitHub

Este panel no usa el usuario de Diego. La llave es un token de GitHub con permiso de escritura solo sobre el repositorio del sistema: sin ese token nadie puede cambiar el abono, aunque abra esta página.

  1. Abrí GitHub → Fine-grained token nuevo.
  2. En Repository access elegí Only select repositories → diegopohl.
  3. En Permissions → Contents elegí Read and write. Poné un vencimiento (por ejemplo 1 año), generá y copiá el token.

El token y la llave de firma quedan guardados cifrados con tu PIN en este navegador. La próxima vez entrás solo con el PIN.

Configuración del abono

Cómo crear el link de Mercado Pago

Opción recomendada: plan de suscripción (cobra solo todos los meses)

  1. Entrá a mercadopago.com.ar → Planes de suscripción con tu cuenta (en la app: Tu negocio → Cobros → Suscripciones). Si es la primera vez, tocá Cobrar con un plan de suscripción.
  2. Tocá Crear nuevo plan. Nombre: Sistema del taller POHL. Precio: el precio del abono de este panel (ya incluye el 7,99%). Frecuencia: Mensual.
  3. En Más opciones: fecha de facturación = el mismo día que el vencimiento de acá; prueba gratis: Sin prueba gratis; duración: Ilimitada.
  4. En Costos y plazos de tu cuenta elegí la acreditación que corresponde a la tasa del 7,99% (dinero al instante).
  5. Guardá el plan, tocá Compartir → Copiar link y pegalo arriba en «Link de pago». Guardá y publicá.

Diego entra una sola vez al link, elige la tarjeta y queda suscripto. Cada mes Mercado Pago le cobra y te avisa: vos registrás el pago acá.

Alternativa: link de pago (Diego paga mes a mes)

  1. En la app de Mercado Pago: Cobrar → Link de pago (en la web: Tu negocio → Link de pago).
  2. Monto: el precio del abono. Descripción: Abono mensual sistema POHL. Elegí que se pueda pagar más de una vez.
  3. Creá el link, copialo y pegalo arriba.

En los dos casos la plata entra directo a tu cuenta de Mercado Pago. Si cambiás el precio, cambiá también el plan o el link.
