Conectá tu cuenta de GitHub

Este panel no usa el usuario de Diego. La llave es un token de GitHub con permiso de escritura solo sobre el repositorio del sistema: sin ese token nadie puede cambiar el abono, aunque abra esta página.

  1. Abrí GitHub → Fine-grained token nuevo.
  2. En Repository access elegí Only select repositories → diegopohl.
  3. En Permissions → Contents elegí Read and write. Generá y copiá el token.

El token queda guardado solo en este navegador. No lo uses en una computadora compartida.
