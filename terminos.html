Términos y condiciones

Última actualización: 24 de noviembre de 2026 (versión 2)

Estos términos regulan el uso del sistema de gestión del taller (el «Sistema») que se brinda a POHL Chapa y Pintura de Pohl Diego Raúl (el «Cliente») y a las personas que este autorice. El Sistema fue desarrollado y es provisto por Cesar Danderfert (el «Proveedor»). Usar el Sistema implica aceptar estos términos.

1. Qué es el Sistema

Es una aplicación web para administrar órdenes de trabajo, presupuestos, recepción de vehículos, inventario, ventas, caja, clientes y usuarios del taller. Se usa desde el navegador del teléfono, la tablet o la computadora.

2. Licencia de uso

  • El Proveedor otorga al Cliente una licencia de uso personal, no exclusiva e intransferible, mientras el abono esté al día.
  • El Sistema, su código, diseño y marcas son propiedad del Proveedor o de sus titulares. No está permitido copiarlo, revenderlo, modificarlo ni usarlo para armar un producto similar.
  • Los datos que carga el Cliente (clientes, órdenes, precios, fotos) son del Cliente.

3. Abono mensual y suscripción

  • A partir del 24 de noviembre de 2026 el uso del Sistema pasa a tener un abono mensual, cuyo valor se informa en la pantalla de ingreso y en Configuración → Abono del sistema. El precio incluye los costos de cobro de Mercado Pago.
  • El abono se paga mediante una suscripción de Mercado Pago (débito automático mensual) u otro medio que indique el Proveedor.
  • Plan vigente sin suscripción: mientras el Cliente no se suscriba, el plan actual se mantiene hasta la fecha de vencimiento informada en el Sistema. El Sistema avisa esa fecha y los días que faltan.
  • Suspensión: si al llegar la fecha de vencimiento el Cliente no se suscribió o no pagó el período, el uso del Sistema se suspende automáticamente a partir del día siguiente. El Proveedor también puede suspenderlo por falta de pago o por incumplimiento de estos términos.
  • Los datos no se borran durante la suspensión: desde la pantalla de suspensión se puede descargar la copia de seguridad.
  • Reactivación: el Sistema se reactiva cuando el Proveedor registra la suscripción o el pago, normalmente dentro de las 24 horas hábiles de informado el pago.
  • El Proveedor puede actualizar el valor del abono avisando con al menos 30 días de anticipación dentro del Sistema.
  • El Cliente puede cancelar la suscripción cuando quiera desde su cuenta de Mercado Pago; el Sistema se puede usar hasta el final del período pagado. Los meses ya pagados no se reintegran.

4. Dónde se guardan los datos

  • La información del taller se guarda en el dispositivo donde se usa el Sistema (almacenamiento del navegador). No se envía a servidores del Proveedor.
  • Es responsabilidad del Cliente descargar copias de seguridad periódicas (Configuración → Copias de seguridad). Si se borran los datos del navegador, se cambia de equipo o se pierde el dispositivo sin copia, la información puede perderse.
  • El Sistema solo consulta por internet si hay actualizaciones y el estado del abono.

5. Datos personales de terceros

El Cliente es responsable de los datos de sus propios clientes que carga en el Sistema (nombre, teléfono, vehículo, fotos, firma) y de usarlos conforme a la Ley 25.326 de Protección de Datos Personales. Los mensajes por WhatsApp y los links de seguimiento los envía el Cliente desde su propio teléfono.

6. Usuarios y contraseñas

Cada usuario es responsable de su contraseña. Las contraseñas se guardan cifradas. Si se olvida, el Proveedor puede habilitar un código de recuperación de un solo uso.

7. Servicios de terceros

El Sistema usa servicios externos como Mercado Pago (cobros), WhatsApp (mensajes), GitHub Pages (publicación) y Google Fonts (tipografías). Cada uno se rige por sus propias condiciones; el Proveedor no es responsable por sus fallas.

8. Disponibilidad y responsabilidad

  • El Proveedor hará lo razonable para que el Sistema funcione correctamente y lo irá mejorando con actualizaciones, que se avisan dentro del Sistema y conservan los datos.
  • El Sistema se brinda «tal como está». El Proveedor no responde por pérdidas de datos causadas por no tener copias de seguridad, por fallas del dispositivo, del navegador o de internet, ni por decisiones comerciales tomadas con la información del Sistema.
  • Los documentos que genera (presupuestos, recibos) no reemplazan a la factura fiscal.

9. Cambios en estos términos

Estos términos pueden actualizarse. La versión vigente es siempre la publicada en esta página.

10. Ley aplicable y contacto

Rigen las leyes de la República Argentina. Para cualquier consulta, comunicate con el Proveedor por WhatsApp o por los medios de contacto habituales.
